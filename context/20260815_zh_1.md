# 全新的博客视觉体验：粒子引擎、毛玻璃导航与沉浸式阅读页

过去的几个月里，这个博客一直在悄悄生长：从 Markdown 渲染模板、目录交互，到评论区 Beta，再到主首页的粒子背景迭代。而这一次，我们把目光放回了文章阅读本身——也就是你现在正在看的这个页面。

本文是一份介绍文档，带你完整认识这次「全新视觉体验」升级的来龙去脉：`pages/article.html` 如何把 **IP 粒子背景引擎**、**悬浮毛玻璃导航栏** 与 **沉浸式排版** 融合到同一个阅读页里，以及它们各自的设计意图与使用方式。

## 为什么重新设计阅读页

文章阅读页是博客内容密度最高、停留时间最长的页面。旧版阅读页（`mobancopy.html`）沿用的是全站通用的固定导航与白底样式，功能完整，但缺少「阅读氛围」：没有阅读进度、没有环境背景、正文与列表页的观感几乎没有区别。

这次升级的目标很明确：

- ✅ **营造阅读氛围**：粒子背景 + 柔光层 + 阅读进度条，让长文阅读不再枯燥
- ✅ **统一视觉语言**：与主首页 `index_new.html` 的毛玻璃导航、日夜分段开关保持一致
- ✅ **强化阅读专注度**：衬线正文、Hero 风格标题、轻量目录，减少视觉噪声
- ✅ **不破坏现有生态**：全部新样式限定作用域，旧页面与旧脚本不受影响

## 视觉主题：昼夜两套「皮肤」

新阅读页不再依赖零散的颜色修补，而是用一套完整的 CSS 变量体系管理主题。白天是温暖的米白底色（`#f4eee4`），搭配低饱和的蓝灰点缀；夜晚切换为深海蓝（`#07172b`），文字转为柔和的冷白。两套皮肤共用同一套变量名，切换时只需要改变 `body` 上的 `light-mode / dark-mode` 类。

| 变量 | 白天（Day） | 夜晚（Night） | 用途 |
|------|------------|--------------|------|
| `--mdx-bg` | `#f4eee4` | `#07172b` | 页面底色 |
| `--mdx-text` | `#202832` | `#edf3fa` | 主文字 |
| `--mdx-text-soft` | `#68717b` | `#aab8c8` | 正文次要文字 |
| `--mdx-accent` | `#5f88a7` | `#8bbbe2` | 强调色（链接、指示条） |
| `--mdx-glass` | `rgba(255,255,255,.58)` | `rgba(15,34,57,.72)` | 毛玻璃卡片底色 |
| `--mdx-border` | `rgba(70,78,86,.10)` | `rgba(190,220,245,.10)` | 边框 |

```css
:root {
    --mdx-bg: #f4eee4;
    --mdx-text: #202832;
    --mdx-accent: #5f88a7;
    --mdx-glass: rgba(255, 255, 255, 0.58);
}

body.dark-mode {
    --mdx-bg: #07172b;
    --mdx-text: #edf3fa;
    --mdx-accent: #8bbbe2;
    --mdx-glass: rgba(15, 34, 57, 0.72);
}
```

有意思的是，这套变量还同步覆盖了旧的组件配色（`--primary-color`、`--text-color` 等），所以目录、评论区、打印分享按钮这些沿用下来的旧组件，也会自动跟随新皮肤——不需要逐个改样式。

## IP 粒子背景：藏在角落里的头像彩蛋

如果说新主题是「皮」，那粒子背景就是「魂」。这一部分源自 `pages/demo/newbottombackgroundbate.html` 的 **IP 粒子引擎**，它把头像图片 `7903.jpg` 逐像素采样成上百个粒子，再让这些粒子带着自己的颜色，在页面右下角缓缓聚合成一幅「粒子画像」。

- **低调的彩蛋**：IP 最大宽度只有 430px，粒子透明度刻意压低（0.18 起），遵循「发现以后才意识到它在那里」的原则，不抢正文
- **鼠标磁场**：鼠标靠近时粒子被柔性排斥并产生切向旋转（是排斥而不是吸附，避免粒子堆积），移动时带出流体拖尾
- **点击脉冲**：按下鼠标会在周围产生一次性的爆发力，让粒子短暂散开再缓缓回归
- **昼夜过渡**：白天粒子保留原图色彩，夜间则向蓝白融合，`themeProgress` 以 0.035 的阻尼系数连续插值，切换主题时背景是「渐变」而不是「跳变」

性能方面同样做了克制：DPR 上限 1.5（保护高 DPI 设备）、空间网格避免 O(n²) 连线、移动端自动把采样间距从 6 提到 9、粒子数量上限按屏幕宽度控制在 850（移动）/ 1500（桌面）。

```javascript
// 只需要修改这一行，就能换成你自己的 IP 图片
const MDX_IP_IMAGE_SRC = "./7903.jpg";

// IP 的最大尺寸：它是背景里的彩蛋，而不是正文里的巨大插画
const MDX_IP_MAX_WIDTH = 430;
```

## 悬浮毛玻璃导航栏

导航栏从「顶部固定、贴边到底」变成了 **顶部居中悬浮的毛玻璃胶囊**：距离顶部 26px、圆角 20px、`backdrop-filter: blur(22px) saturate(130%)`，滚动时背景内容在玻璃下微微虚化，层次感一下就出来了。

导航栏内的三段式布局：

1. **品牌区**：头像 + 站点名，点击回到首页
2. **导航区**：首页 / 博客 / 链接 / 简历 / 关于，当前页自动高亮
3. **操作区**：GitHub、Email 图标按钮 + 日夜分段开关 + 中/EN 语言滑块

### 日夜切换：与全站彻底打通

新的分段开关（☀ Day / ☾ Night）并不只是一页之内的玩具，它直接驱动全站的主题约定：

```javascript
document.body.classList.remove("light-mode", "dark-mode");
document.body.classList.add(nextDark ? "dark-mode" : "light-mode");
localStorage.setItem("theme", nextDark ? "dark-mode" : "light-mode");
```

也就是说，你在阅读页切换到夜晚模式，回到首页、博客列表依然是夜晚模式——`localStorage` 里的偏好是同一个。同时粒子背景、代码高亮（atom-one-light / dark）也会同步切换。为了让 `js/theme.js` 这类旧脚本仍然兼容，页面里保留了一个隐藏的旧版 `theme-toggle` 占位节点。

### 中英文切换：复用全站双语机制

语言滑块同样复用了 `language.js` 的 `data-en / data-zh` 体系：点击 EN，滑块平滑右移，页面所有带双语标记的文案一次性更新，并广播 `sitewide-language-change` 事件——阅读页监听到这个事件后会按 `_zh.md ↔ _en.md` 配对规则自动重载对应语言的文章。

> 一个小细节：语言切换只改写要加载的 Markdown 文件路径，不会改动地址栏里的查询串，方便分享链接保持语言中立。

## 阅读进度条与沉浸式排版

页面顶部有一条 2px 高的渐变进度条，随着滚动平滑推进，让读者随时知道「这篇文还剩下多少」。这属于很轻的视觉反馈，不打扰阅读，却极大地提升了长文的掌控感。

正文排版则是这次升级中最「安静」也最花心思的部分：

- **Hero 风格标题**：衬线字体（Georgia / Noto Serif SC），`clamp(34px, 4.2vw, 54px)` 自适应字号，负字距让大标题更紧凑有力
- **衬线正文**：段落行高 2.0，中文长文读起来更从容；`strong` 加粗用主文字色，强调而不刺眼
- **圆角代码卡片**：代码块变成 18px 圆角的柔和卡片，暗色模式下是深蓝近黑的底色
- **玻璃评论区**：评论区收敛为一张毛玻璃卡片，保留草稿自动保存与提交冷却
- **细节元素**：分隔线是 80px 宽的渐变短线；引用块是 3px 强调色左边线；图片统一 20px 圆角

数学公式方面，这次还顺手修了一个误判：正文中的金额区间（如 $1,900→$2,040）会被误认为行内公式，渲染出过宽且不可折行的 KaTeX 片段。渲染器新增了防误判规则——含中文、Markdown 语法、破折号/箭头，或是不含任何 LaTeX 命令的自然语言短语，一律按原文处理：

```javascript
if (/[\u4e00-\u9fa5]|\]\(|!\[|\*\*|→|–|—/.test(formula)) {
    return match; // 保持原文，不按公式处理
}
```

## 目录与阅读工具

右侧目录做成了 Notion 风格的轻量面板：无边框、局部滚动且隐藏滚动条、悬停轻微放大、当前项右侧有一条 3px 强调色指示条。滚动阅读时，目录会实时高亮当前章节，并自动把高亮项滚入可视区域。折叠按钮支持三级标题的展开/收起。

文章头部保留了四个阅读工具：**打印、分享、全屏、字号**。其中字号支持「标准 / 较大 / 特大 / 小号」四档循环，偏好写入 `localStorage`，下次打开同一页面会自动恢复。

## 文档与使用指南

如果你是站长或协作者，这套阅读页的使用方式如下：

### 加载一篇 Markdown 文章

在 URL 上通过 `md` 或 `file` 参数指定文件路径：

```
pages/article.html?md=../../context/20260815_zh_1.md
```

页面会按当前语言自动解析 `_zh.md ↔ _en.md` 配对：URL 写 `20260815_zh_1.md`，切到英文时会自动尝试加载 `20260815_en_1.md`；带数字后缀的系列文章（`_zh_1`、`_zh_2`）同样支持配对。

### 配置默认文章与元信息

如果不带参数，则加载 `PAGE_CONFIG` 中配置的默认文件与默认元信息：

```javascript
const PAGE_CONFIG = {
    defaultMarkdownFile: '../../context/test_zh.md',
    articleMeta: {
        title: 'Markdown测试文章',
        title_en: 'Markdown Test Article',
        date: '2026-08-15',
        category: '技术',
        category_en: 'Technology',
        tags: ['Markdown', '博客', '视觉体验'],
        tags_en: ['Markdown', 'Blog', 'Visual Experience']
    }
};
```

文章标题以 Markdown 首行 `# 标题` 为准（渲染后会自动从正文中移除，避免重复）；日期、分类、标签则优先从 `blog-posts-data.js` 注册的元信息中读取。

### 自定义 IP 图片

把头像图片放到 `pages/blog/` 目录下，修改 `MDX_IP_IMAGE_SRC` 即可（图片建议保持正方形或接近正方形，粒子采样效果最佳）。

## 兼容性与设计原则

最后聊聊这次升级最重要的一个约束：**不破坏任何旧东西**。

- 新样式全部限定在 `mdx-*` 与 `.md-article-layout` 作用域内，旧版文章页、首页、博客列表完全不受影响
- 旧模板 `mobancopy.html` 作为备份保留，随时可以对照回退
- 响应式三档断点（1250 / 900 / 580px）：窄屏隐藏文字导航与语言滑块，移动端体验保持完整
- 支持 `prefers-reduced-motion`，系统开启「减少动态效果」时动画过渡会被大幅缩短
- 脚本语法校验：本次所有内联脚本均通过 `node --check` 检查

## 结语

从今天起，博客的文章页不再是「白色背景 + 正文」的默认模板，而是一个有温度、有层次的阅读空间：粒子在角落呼吸，玻璃导航悬浮其上，进度条默默记录你的阅读旅程，昼夜与中英随时一键切换。

技术本身并不复杂——不过是一层 CSS 变量、一段 Canvas 采样、几个事件监听——但当它们组合在一起，阅读就变成了一种更愉悦的体验。希望你喜欢这个全新的博客阅读页，也欢迎在评论区留下你的反馈。
