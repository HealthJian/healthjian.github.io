Security
隐私不是一句承诺，
是写进架构的约束。

「无云」不靠自觉 —— 页面被 CSP 强制只能连接自身，技术上就无法把数据发往任何外部地址。本地服务只监听 127.0.0.1，端口随机、令牌每次启动重生成。

1

Host 回环校验

只接受发往 127.0.0.1 的请求，同机其它程序无法冒名访问。

2

Origin / Referer 白名单

浏览器里的其它网页无法跨域调用你的账本接口。

3

一次性会话令牌

每次启动生成随机令牌，只存内存，进程退出即失效。

4

路径穿越防护

静态资源与附件访问均做路径校验，无法越界读取文件。

Principles

几条雷打不动的原则。

好的产品懂得说什么「不」。这些取舍写在代码里，也写在文档里。

RULE / 01

金额一律用整数分

从数据库到界面，所有金额以「分」为单位的整数存储与计算，彻底杜绝浮点误差。汇总以人民币为口径，未配汇率时绝不把不同币种直接相加。

「1 分钱的误差也不允许复利成信任危机。」
RULE / 02

刻意的不预置

法定节假日表不内置、五险一金比例不预置 —— 因为它们每年每城都在变。界面明确标注「待配置」，而不是显示一个看起来权威的错误数字。

「一个错的发薪日，比没有更糟。」
RULE / 03

每个数字都可解释

K 线降周期会明确告知，日历指标有公开的口径文档，五险一金保底封顶会报出收敛原因，跳过任务必须填写理由。

「不显示来源不明的权威数字。」

Technology

小体积，严肃工程。

复用系统 WebView2 运行时，安装包只有几十 MB —— 但内核毫不妥协。

桌面外壳
pywebview + WebView2
复用系统运行时；不可用时自动降级为浏览器外壳，绝不静默失败。
本地服务
FastAPI + Uvicorn
只监听 127.0.0.1，随机端口 + 每次启动随机令牌。
界面
React 18 + TypeScript
Vite 构建，Tailwind 驱动 Apple 风格设计令牌，日 / 夜 / 跟随系统。
数据
SQLite + Alembic
全本地存储，启动自动迁移；升级前自动完整备份，失败即中止。
